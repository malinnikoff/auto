# Лендинг «Новая машина в США» · @dmitry_miami

## Что в папке

| Файл | Что это |
|---|---|
| `index.html` | Сам лендинг: страница и анкета из 3 шагов |
| `privacy.html` | Политика конфиденциальности |
| `apps-script/Code.gs` | Приём заявок: Google Таблица + уведомления в Telegram и на email |
| `assets/` | Сюда кладутся фото (см. ниже) |

Пока в `index.html` не указан адрес приёма заявок (`ENDPOINT`), форма **не делает вид, что отправила заявку**: она показывает ошибку и предлагает написать в Instagram.

---

## Шаг 1. Telegram-бот (5 минут)

1. В Telegram откройте **@BotFather** и отправьте `/newbot`.
2. Придумайте имя, например «Заявки Дмитрий Майами», и username, который заканчивается на `bot`.
3. BotFather пришлёт **токен** вида `1234567890:AA...`. Сохраните его, никому не пересылайте.
4. Откройте своего нового бота и нажмите **Start** (или отправьте `/start`), иначе он не сможет вам писать.

## Шаг 2. Google Таблица и скрипт

1. Создайте новую Google Таблицу, например «Заявки авто».
2. В меню: **Расширения → Apps Script**.
3. Удалите всё в файле `Code.gs` и вставьте содержимое `apps-script/Code.gs` из этой папки. Сохраните.
4. Слева **⚙ Project Settings → Script properties → Add script property**:
   - `TELEGRAM_TOKEN` = токен из шага 1
   - `NOTIFY_EMAIL` = почта для копии уведомлений (необязательно)
5. Вверху выберите функцию **setup** → **Run**. Google попросит разрешения: разрешите (это ваш собственный скрипт). В таблице появятся листы «Заявки» и «Договоры», а в вашем Google Drive папка «Договоры с сайта» для файлов на проверку.
6. Выберите функцию **getChatId** → **Run**. Внизу в журнале будет `chat id: 123456789`. Добавьте свойство:
   - `TELEGRAM_CHAT_ID` = это число
7. Выберите **testNotify** → **Run**. Должно прийти тестовое сообщение в Telegram.
8. **Deploy → New deployment → ⚙ Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - Нажмите Deploy и скопируйте **Web app URL** (вида `https://script.google.com/macros/s/.../exec`).

## Шаг 3. Подключить сайт

В `index.html` найдите блок `CONFIG` внизу и вставьте URL:

```js
ENDPOINT: "https://script.google.com/macros/s/.../exec",
```

По желанию укажите `WHATSAPP` (только цифры с кодом страны). Тогда при сбое отправки человек увидит кнопку «написать в WhatsApp» с уже заполненной заявкой.

> Если вы потом меняете `Code.gs`, делайте **Deploy → Manage deployments → ✎ → Version: New version**. Тогда URL останется прежним.

## Шаг 4. Проверка

Отправьте 2 тестовые заявки с телефона: одну через Wi-Fi, другую через мобильный интернет. Проверьте, что:
- в таблице появились строки с номером, временем и меткой;
- в Telegram пришли уведомления;
- на сайте показался экран «Заявка у меня» с номером.

Тестовые строки потом удалите или поставьте им статус «Не целевая».

## Ссылки для Instagram

Метки нужны, чтобы видеть в таблице, откуда пришёл человек.

- Шапка профиля: `АДРЕС_САЙТА/?utm_source=instagram&utm_medium=bio`
- Кодовое слово «договор»: `АДРЕС_САЙТА/?utm_source=dogovor&utm_medium=dm`
- Конкретный рилс: добавьте `&utm_content=название-рилса`

## Проверка договоров

Форма в блоке «Проверим ваш договор бесплатно» принимает до 10 файлов (фото или PDF). Фото сайт сам сжимает перед отправкой, общий лимит после сжатия 12 МБ.
- Файлы сохраняются в папку «Договоры с сайта» на вашем Google Drive, по отдельной папке на каждую заявку.
- Строка с контактами и ссылкой на файлы появляется на листе «Договоры».
- В Telegram приходит уведомление «ДОГОВОР НА ПРОВЕРКУ» с кнопками «Открыть файлы» и «WhatsApp».
- В колонку «Заметки / найдено $» удобно записывать, сколько нашли, это готовые цифры для Reels. Показывать договоры можно только обезличенными: без имени, телефона, адреса, VIN, названия дилера и редких деталей, по которым человека можно узнать (так написано в политике конфиденциальности).

Статусы: Новая → Разбираем → Разбор отправлен → Перешёл в покупку / Не целевая.

Папку с договорами не открывайте для общего доступа: в файлах могут остаться личные данные.

## Статусы заявок в таблице

Новая → Связался / Не дозвонился → Передана партнёрам → Предложение отправлено → Сделка / Отказ / Не целевая

По этой колонке через месяц будет видна реальная воронка: сколько заявок, сколько дозвонов, сколько предложений и сделок.

## CRM

Когда CRM будет готова, добавьте в свойства скрипта `CRM_WEBHOOK_URL`. Новые заявки начнут уходить туда автоматически, а результат будет записываться в колонку «CRM». Старые заявки переносятся выгрузкой таблицы в CSV.
